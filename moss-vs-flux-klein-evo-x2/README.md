# MOSS Image (two steps) vs FLUX.3 Klein SD: EVO-X2 test (1 Nov 2026)

Measurement files for the Dolmario Local AI video. No model weights, program code, private pictures, prompts, generated images or reference audio.

**Setup:** GMKtec EVO-X2, Ryzen AI Max+ 395, 64 GB shared memory, Windows. Same text prompt, two seeds, 1024 x 1024, each model's own supported recipe. Time = submit to saved image, one measurement per profile; the first runs include model loading.

Warm times (seed 22): MOSS IDM two steps 9.0 s, FLUX.3 Klein SD four steps 12.1 s, sixteen steps 33.1 s. Two seeds cannot decide overall quality or character consistency.

Files: `RESULTS.csv` (ten runs), `METHOD.txt`, `SOURCES.txt`, `LICENSE-NOTES.txt`. Integrity: `SHA256SUMS.txt`. Licence notes record the declarations of the upstream model cards, not a general clearance.
