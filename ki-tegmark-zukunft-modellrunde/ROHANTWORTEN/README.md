# Originaldateien und Index
Die enthaltenen Antwortdateien sind bytegleich zu den jeweils zugeordneten Originalen. Modell-/Harness-/Rundenlabel und technische Bedingungen stehen im INDEX.json, nicht als nachträglich eingefügter Kopf im Antworttext. Physische SHA256-Dateihashes stehen im Index und in SHA256SUMS.txt.

Keine Denkspuren, API-Rohrequests, Sitzungstitel oder lokalen Konfigurationsdateien enthalten. Dateien mit privaten Hinweisen wurden vollständig zurückgehalten, nicht im Text redigiert. Ein Hash ohne Antwortdatei bedeutet daher keinen veröffentlichten Antworttext. Ausgeschlossene Aufbaupiloten gehören nicht zu gültigen Modellfällen. Fehlende Schlussantworten sind im technischen Index erkennbar. Dies ist keine inhaltliche Prüfung der Antworten.
