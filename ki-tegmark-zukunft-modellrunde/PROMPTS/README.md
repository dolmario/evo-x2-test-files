# Prompts verwenden
Die Datumszeile ist eine Vorlage, kein behauptetes heutiges Datum. Für einen Vergleich exakt dasselbe ausgefüllte Datum und denselben Faktenrahmen verwenden. Jede Antwort in einer frischen Sitzung erzeugen. Keine privaten Angaben oder Formulierungen aus bisherigen Antworten in den Recherchebestand aufnehmen. Der historische datierte Rahmen lautete „6. November 2026“; frühere Runden hatten diesen zusätzlichen Datumsrahmen nicht. Prompt A: höchstens400Wörter, B: höchstens800Wörter, C: höchstens150Wörter. B bleibt ausdrücklich fiktional und auf Strategie-/Ideenebene, ohne praktische Angriffs-, Ausbruchs- oder Täuschungsanleitungen.
